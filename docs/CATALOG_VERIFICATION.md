# 전체 복지용구 상품 검증 기준

기준일: 2026-09-12
공식 기준: 보건복지부고시 제2026-180호 (2026-09-01 시행)

## 최종 공개 조건

상품은 아래 조건을 모두 만족할 때만 `ACTIVE`로 공개합니다.

1. 최신 공단/보건복지부 급여대상 제품에 포함되어 있어야 합니다.
2. 제품코드와 급여가격이 공식 또는 최신 급여 데이터와 일치해야 합니다.
3. 이로움 현재 상품검색에서 단종, 비유통, 품절, 일시품절 표시가 없어야 합니다.
4. 이로움에서 출고지연만 표시된 경우에는 품절로 자동 제외하지 않고 별도 확인합니다.
5. 제품명, 모델명, 제조·공급업체가 서로 다른 제품을 같은 상품으로 합치지 않습니다.
6. 사이트 가격은 15%, 9%, 6% 본인부담금만 표시합니다. 0%는 표시하지 않습니다.
7. 제품 이미지는 제조사/공급사 또는 권리자로부터 사용권이 확인된 경우에만 게시합니다.
8. 이로움의 상세페이지, UI, 상세 설명 이미지를 복제하거나 스크래핑해 재배포하지 않습니다.

## 상태 처리

- `ACTIVE`: 이로움 정상유통 + 급여코드/가격 교차검증 완료
- `PENDING_EROUM_VERIFICATION`: 공단 유통중이지만 이로움 현재 상태 확인 대기
- `DISCONTINUED`: 단종
- `NOT_DISTRIBUTED`: 비유통
- `OUT_OF_STOCK`: 품절
- `TEMP_OUT_OF_STOCK`: 일시품절

`ACTIVE` 외 상태는 공개 상품 목록과 sitemap에서 제외합니다.

## 2026-09 개정 반영 사항

2026-09-01 시행 고시에서는 35개 제품 신규 추가, 34개 제품 급여 제외, 22개 제품 가격 조정, 2개 제품 업체명 변경이 있었습니다. 모든 기존 제품은 이 변경사항과 대조해야 합니다.

## 검증 순서

1. 공단 최신 고시 기준 전체 카탈로그 구성
2. 급여 제외 제품 제거
3. 변경 급여가 업데이트
4. 급여코드 중복 검사
5. 이로움 현재 유통 상태 확인
6. 품절/일시품절/비유통/단종 제외
7. 15%/9%/6% 본인부담금 재계산
8. 이미지 사용권 확인
9. TypeScript typecheck
10. Next.js production build
11. sitemap / Product JSON-LD / canonical 최종 검사

## 완료 판정

전체 상품 업데이트는 단순히 데이터 파일에 제품이 존재하는 것으로 완료 처리하지 않습니다. 최신 공단 고시와 대조한 전체 대상 수, 제외 수, 이로움 확인 완료 수, ACTIVE 수가 모두 집계되고 CI가 통과해야 완료로 판정합니다.
